# ネオジオ ブラウザエミュレータ(シム群馬)

ブラウザで動くネオジオ(MVS/AES)エミュレータです。異能ソフトのオリジナル作品「シム群馬」と、チーム自作のTEST BIOSを同梱しています(SNK純正BIOS等は使用していません)。

## 操作
- 矢印キー: レバー
- Z / X / A / S: A〜Dボタン
- Enter: START
- 5: COIN

## URLオプション
- `?sys=aes` : AESモードで起動
- `?pad=1` : PCでも仮想パッドを表示

## 注意
- エミュレータ上でのみ確認しています。実機での動作は未確認です。
- セーブ機能はまだありません。
