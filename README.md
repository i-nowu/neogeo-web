# ネオジオ ブラウザエミュレータ(シム群馬)

ブラウザで動くネオジオ(MVS/AES)エミュレータです。異能ソフトのオリジナル作品「シム群馬」と、チーム自作のTEST BIOSを同梱しています(SNK純正BIOS等は使用していません)。

## 操作
- 矢印キー: レバー
- Z / X / A / S: A〜Dボタン
- Enter: START
- 5: COIN

## URLオプション
- `?sys=aes` : AESモードで起動
- `?pad=1` : PCでも仮想パッドを表示

## 自分のROM・BIOSで遊ぶ
市販ソフトのROM・BIOSは配布していません。ご自身が正当に所有するものをご利用ください。ファイルはブラウザ内でのみ処理され、送信されません。

1. 画面下の「ROM読込」を押します。
2. BIOSの種類（MVS / AES / Universe BIOS）を選びます。
3. BIOS（MAME形式の `neogeo.zip`）と、ゲーム（`.neo` ファイル、または `.neo` を1つ含むZIP）を選ぶか、枠にドラッグ＆ドロップします。
4. 「起動」を押します。「この端末に保存」にチェックすると、IndexedDB（この端末内だけ）に保存され、次回は「保存したもので起動」で遊べます。「保存を削除」で消せます。
5. 「内蔵ゲーム」でシム群馬に戻ります。

対応形式:
- BIOS ZIP 内のファイル名: MVS `sp-s2.sp1` / `sp-u2.sp1` / `japan-j3.bin` / `sp-45.sp1`（あるものから地域を自動選択）、AES `neo-po.bin` / `neo-epo.bin`、Universe `uni-bios_4_0.rom`。共通で `000-lo.lo`、MVS/Universeは `sfix.sfix` も必要です。
- ゲーム: `.neo` 形式のみ。MAME形式の分割ROM ZIP（`.p1` `.c1` などが入ったもの）はそのままでは読めません。`.neo` 形式に変換したものを使ってください。

## 注意
- エミュレータ上でのみ確認しています。実機での動作は未確認です。
- セーブ機能はまだありません。
